## Scope and ownership

Reviewed the starter/CLI, distribution boundary, landing, Examples, authored Docs
and source-backed component/integration references. Cross-project frontend review
covered EasyTrip, All Influencers, Dinkbit, Astro5, PetSpa, Ticker and Drawer as

## Skills and portable context

samline-astro ships with generated projects and reads current source, installed
features and portable frontend conventions. samline-astro-maintainer stays in
this repository. Both passed the official validator using a disposable Python
environment; independent realistic scenario reviews found no new contradiction.
A real generated-project locale-add scenario preserved a custom current key,
created empty French values and kept the locale inactive.

Root/CLI README explain purpose, release availability, defaults, optional features,
source ownership, updates, local packaging and licenses. Component docs remain
next to source and feed the website. The website is excluded from CLI/consumer
output, while selected portable agent context is intentionally included.

## Update boundary

Official Astro upgrade research is documented in update-plan.md and the public
Update a project guide. The official temporary executable previews/updates Astro
and installed official integrations. Other dependencies are reviewed separately.
There is no automatic copied-source updater today; the metadata does not provide
pristine baseline hashes for three-way merging. Neither add nor kit:version is an
update/merge command. No framework major upgrade was performed in this audit.
