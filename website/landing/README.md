# Package landing

Home and Examples compose the shared document and sections. Content is owned by
src/i18n/translations/en. Hero, Features, Runtimes, GettingStarted, Recipes, FAQ
and closing retain the template presentation. Packages is the human-requested
curated Drawer/Ticker/Forms section. Its decorative illustrations are not demos.
The real CLI recipe explorer is shared with Docs through shared/components/Playground.

Use bun run site:dev/check/build/verify from the repository root. Do not install
this app separately with another manager or embed the maintained starter app
into this public website. Read ../README.md and ../AGENTS.md for editorial,
performance, licensing and publication boundaries.
